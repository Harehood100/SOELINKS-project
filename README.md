# SOELinks Ltd — Official Website

> **Precision. Passion. Performance.**  
> Corporate website for SOELinks Ltd, a Lagos-based company specialising in Project Management, Construction & Development, Interior Architecture & Design, Strategic Consulting, and Real Estate Development.

🌐 **Live Site:** [https://harehood100.github.io/SOELINKS-project/]

---

## Pages

- **Home** — Hero section, services overview, process steps, why us, and CTA
- **About** — Company story, vision & mission, core principles, and founder profile
- **Services** — Detailed breakdown of all 5 service offerings with process flow
- **Contact** — Contact details (phone, WhatsApp, email, Instagram) and enquiry form

---

## Tech Stack

| Technology | Purpose |
|---|---|
| HTML5 | Page structure and content |
| CSS3 | Styling, layout, responsive design |
| Vanilla JavaScript | Page navigation, mobile menu, form interaction |
| Google Fonts | Cormorant Garant (display) + Inter (body) |

No frameworks. No dependencies. Pure HTML, CSS, and JavaScript.


## Getting Started Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/Harehood100/
SOELINKS-project.git
   ```

2. Open the project folder in VS Code:
   ```bash
   cd 
SOELINKS-project
   code .
   ```

3. Install the **Live Server** extension in VS Code, then right-click `index.html` → **Open with Live Server**

No build step or package installation required.

---

## Deployment

This site is deployed via **GitHub Pages**.

To redeploy after making changes:

```bash
git add .
git commit -m "your update message"
git push
```

GitHub Pages will automatically reflect changes within a few minutes.

To enable GitHub Pages on a new repo:
1. Go to **Settings → Pages**
2. Set Branch to `main` and folder to `/ (root)`
3. Click **Save**
